# ADR-0015：Ozon 财务报告双版本路由

- 状态：Accepted
- 日期：2026-07-20
- 切换日：2026-08-03

## 背景

Ozon Seller 页面提示，2026-08-03 后旧商品报告将由应计费用报告替代。直接替换解析器会破坏历史重放；仅靠文件名猜测又可能把收入、补偿或折扣误作费用。

## 决策

1. 旧商品报告与应计费用报告合同并存。
2. 路由同时使用声明报告期间和可识别的原始结构；两者冲突或期间跨越切换日时进入差异队列。
3. 每个 Import 固化 `report_type`、`schema_version`、路由依据和声明期间。
4. 两类报告统一经过：原始 Evidence → 暂存行 → 分类 → 差异队列 → 独立复核 → 控制事实。
5. 新合同不得覆盖、重写或回填旧历史行；未知字段保持原样并等待人工映射。

## 回滚

可以暂停新版本路由并保留原始 Evidence 与暂存行。禁止通过删除新解析器的方式回滚已导入历史。
