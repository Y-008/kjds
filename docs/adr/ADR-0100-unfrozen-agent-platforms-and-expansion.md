# ADR-0100：解冻新 Agent 平台与长期 Agent 扩编

## 状态

Accepted（经营负责人 2026-08-15 口头指令，待签字确认）。不改变任何 API、数据、身份或权限合同。

## 背景

ADR-0098 与 BR-149 将「新 Agent 平台」「长期 Agent 扩编」纳入 90 天冻结；现场裁决 DeepSeekHarness「现在不装」。经营负责人 2026-08-15 指令：两项解冻，可引入，并安装 DeepSeekHarness。

## 决定

1. 「新 Agent 平台」解冻：可候选评估与引入（L3 拍板）。
2. 「长期 Agent 扩编」解冻：可经 L3 拍板引入。
3. 引入的新 Agent 平台与扩编 Agent 永不获得付款、调价、改库存或外写权限；仍遵守三层终审、双模型校验、Readback 与证据存证。
4. 其余冻结项（新国家、新平台、第二任务/审批/事实系统等）不变。

## 边界

- 解冻不等于已接入生产；每个平台/Agent 引入仍需独立候选评估：官方来源、许可证、数据边界、成本、回滚与卸载 Gate。
- DeepSeekHarness 安装只落本地隔离环境，不触达 Ozon 账号与经营外写。
