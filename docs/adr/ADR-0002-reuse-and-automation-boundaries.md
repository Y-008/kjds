# ADR-0002：优先复用成熟工具，并隔离商业授权边界

- 状态：Accepted
- 日期：2026-07-12

## 决策

KJDS 只自行实现跨境电商领域事实、利润口径、审批政策、实验反馈和租户数据边界。通用能力优先通过稳定 API 复用成熟项目：

| 能力 | 采用工具 | 使用边界 |
|---|---|---|
| 内部可视化自动化 | 已有 `D:\AI\Stacks\n8n-local` | 仅限经营者自己的内部部署；KJDS 不再部署第二套，不嵌入或转售 |
| 商业版可视化自动化候选 | Activepieces CE | MIT 社区版；嵌入功能上线前再次审计企业功能边界 |
| 图片和视频工作流 | 已有 `D:\AI\Apps\ComfyUI-latest` | GPL-3.0 独立进程，使用本机 8189 端口；复用已有工作流，只通过 API 调用 |
| 本地语言/视觉推理 | Ollama | 独立本地运行时；模型权重逐个登记许可证 |
| 多模型统一接口 | LiteLLM OSS 或 PydanticAI | 使用允许商业分发的 OSS 部分；不复制 enterprise 目录 |
| 后台任务 | PgQueuer/Procrastinate | PostgreSQL 原生任务队列，避免自制锁、重试和调度器 |
| 管理端组件 | Next.js + shadcn/ui | 保留 MIT 许可证通知 |

## n8n 特别约束

n8n 使用 Sustainable Use License，允许内部业务使用，但不允许将社区版作为 KJDS 商业产品的一部分分发或向客户提供。内部版可通过 Compose profile 启动，并只调用 KJDS 的公开 API；所有业务规则仍在 KJDS 服务层，确保移除 n8n 不会丢失业务能力。

## 采用原则

1. 外部工具一律放在 Provider/Connector 后面，不能拥有 KJDS 的业务事实。
2. 工作流只传 ID 和最小必要数据，平台密钥不进入 Agent 提示词。
3. 固定镜像/包版本并记录来源、许可证和哈希；升级必须经过回归测试。
4. 项目内维护第三方清单。GPL、source-available 或模型特定许可证必须保持进程隔离并显示商业限制。
5. 没有成熟工具覆盖的部分才自行实现，并在代码评审中说明原因。

## 后果

内部运营可以快速使用 n8n 和 ComfyUI；未来销售软件时，核心产品不会被 n8n 的商业限制锁死。通用工具可以替换，而利润、证据、审批和实验历史保持不变。
