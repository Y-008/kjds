# BAS-057 Ozon 财务报告期间交接合同

## 交付结论

Ozon 财务文件的“预期报告期间”不再依赖口头说明或复核人记忆。上传人必须提交查询起止日期，系统标准化后与原文件哈希一起固化到不可变 Evidence；复核人看到并核对的是同一结构化期间。

## 最小实现

- 复用现有 `POST /v1/imports/ozon`、Evidence、财务来源复核和 Web 交接界面。
- 上传参数增加 `report_period_start` 与 `report_period_end`，格式为 `YYYY-MM-DD`。
- 所有带时间窗口的 Ozon 导入都必须在 API 边界提交两端日期；服务端拒绝缺失、空值、日期无效、起止倒置和超过 31 天的期间。
- 同一文件哈希仅在原 Evidence 存在且固化期间完全相同时返回既有导入；旧 Evidence 无期间、血缘缺失或改报其他期间时返回 `409`，不得把重复上传变成期间重声明旁路。
- 财务复核状态回显固化期间，复核 Evidence 同时保存该期间。
- 财务原件没有期间，或已有复核记录中的期间与原件不一致时，复核与事实晋升均失败关闭。
- 普通订单导入保留期间上下文但不进入财务复核；复核通过也不自动入账、映射或对账。
