## 账户负责人只需完成两项决定

### 决定 1：Ozon Data 条款

- 阅读页面链接的 Ozon 要约与个人信息处理条件；
- 若本人接受，在 Ozon 页面亲自勾选并继续；若不接受，记录拒绝，不由 Agent 代签；
- 进入后只确认是否存在俄罗斯/Ozon、类目或全市场、最近不少于 28 天且可导出的真实报告；
- 如有付费条件，先记录套餐、币种、含税价格、周期、自动续费/取消条件和报告范围，再单独批准支出。

### 决定 2：Ozon API 身份收敛

- 对现有 7 个宽权限 Key 逐个登记脱敏引用、调用系统、Owner、最后使用时间、保留理由和撤销路径；
- 明确批准后新建一个 KJDS 专用产品只读身份，只授予单 SKU 试运行所需角色；
- Key 值只进入本机或托管秘密存储，不进入仓库、日志、截图、对话或本文件；
- 由不同人员复核权限范围后，才可运行一次已批准 offer 的影子 Pilot。

## 原件取得后的固定交接

```text
Ozon Data 原文件
→ 记录账户、导出时间、筛选条件和不少于 28 天窗口
→ 计算 SHA-256
→ 上传为 SKU-000 Evidence
→ 非上传者核验真实性、范围、非示例属性和哈希
→ 接受后才建立三个候选
```

报告取得只解除需求数据阻塞，不批准候选、采购、定价、图片、Listing 或发布。

## 失败关闭条件

- 页面只有示例、截图、汇总读数或我方已有 SKU 数据；
- 报告窗口少于 28 天，或无法保留原始文件；
- 付费前无法确认报告范围、自动续费或取消条件；
- 使用现有 35 角色宽权限 Key 试跑；
- 上传人与复核人为同一身份；
- 任一凭证或个人数据出现在仓库、日志或交接文档。
