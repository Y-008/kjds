# BAS-073：Ozon 财务独立复核只读交接包

## 结论

工程侧已把 Ozon 财务导入的复核交接从“只显示导入编号与状态”升级为可复算的只读聚合核验包。核验包帮助不同身份的 Reviewer/Compliance/Admin 比对原文件与暂存结果，但不会代替其确认账户来源、报告期间、非公开样例和导出完整性，也不会自动接受、分类、晋升事实或入账。

状态：`DONE_ENGINEERING`。真实业务状态仍为 `pending`，不能宣称财务闭环完成。

## 问题与设计边界

原复核页缺少文件哈希、大小、上传者、解析覆盖、精确金额合计和计提组合，第二位复核人无法在提交结论前有效判断交接完整度。

本次直接扩展既有复核状态端点与既有 Web 表单，没有新增服务、数据库表、消息队列或依赖。返回内容只包含：

- 原文件名、SHA-256、字节数、内容类型、上传者和捕获时间；
- 导入类型、状态、总行数、接受/拒绝行数和标准化字段；
- Evidence 有效性、哈希一致性、来源血缘和行号连续性；
- 逐币种 Decimal 精确合计、最早/最晚生效时间；
- 计提文件实际出现的组/类型、行数和逐币种合计。

明确不返回商品、订单、客户等原始行，不执行自动接受、自动会计分类或自动财务入账。正式晋升路径的接受检查不计算展示用聚合包，避免把 UI 读取成本耦合进财务 Gate。
