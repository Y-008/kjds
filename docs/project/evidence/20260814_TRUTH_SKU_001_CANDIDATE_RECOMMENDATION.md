## 4. 被冻结候选的完整证据采集（落到该 SKU，缺一即 `BLOCKED_EVIDENCE`）

1. SKU Passport：Product/SKU/Ozon offer 稳定映射、名称/材质/用途/产地、实测重量/长宽高。
2. 供应商报价：同一 SKU 三家真实报价（报价 ID、MOQ、单价/币种、交期、重量尺寸、国内物流、有效期）。
3. 合规：HS、EAEU/EAC、Честный ЗНАК（若适用）、俄文标签、知识产权、运输限制。
4. Ozon 访问/API 身份：脱敏只读作用域盘点，不录密钥。
5. 财务五段：`order_id → posting_number → 平台费用/结算 → 银行到账 → FX`，含银行流水备注 reconciliation key。
6. 独立复核：提案人 ≠ 复核人，只接受原始文件 + SHA-256 + 时间 + Owner。
