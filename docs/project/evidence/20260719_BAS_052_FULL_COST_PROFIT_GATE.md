# BAS-052 全成本利润与证据门禁验证

## 结论

利润场景已从“CM3 为正即可继续”升级为“CM3 为正、十五类成本逐项有证据、且无未分类成本才可继续”。证据不完整的场景仍可作为测算草稿保存，但供应商采购评审、样品下单、备选供应商推荐和 Ozon Listing 草稿均失败关闭。

## 实现边界

- 新增显式成本：仓储、税费、汇兑费用、资金占用、售后和损耗准备；保留 `other_cost` 仅兼容历史草稿，非零即不可放行。
- 十五类成本证据键覆盖采购、国内头程、国际物流、包装、仓储、关税、税费、尾程、平台佣金、广告、退货、汇兑、资金占用、售后和损耗。
- 供应商报价原件自动证明采购与国内头程；三报价入口的利润假设文件必须是覆盖其余成本项（包括零值/不适用）的完整费用包。
- 决策时由比较与采购候选门禁检查，执行时由样品下单和 Listing 草稿再次检查。
- PostgreSQL 迁移 `20260719_0037` 保存六类金额和逐项证据映射，并拒绝负的具名成本。

## 剩余真实输入

- 每个候选 SKU 的完整费用包和三家供应商原始报价尚未提供。
- Ozon 店铺结算、广告、退款原件，跨境巴士真实订单/计费重/仓储账单，税单和 booked FX 尚未进入 Evidence。
- 因此当前能力是“正确计算并阻止缺证据放行”，不是“已确认某商品可以买到且可盈利”。
