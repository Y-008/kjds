# BAS-074：Ozon 计提分类币种与符号不变量

## 结论

计提分类现已执行而非仅记录“预期符号”，并禁止跨币种伪合计。该修复位于既有 `OzonAccrualClassificationService`，未增加服务、规则引擎、数据表或依赖。

状态：`DONE_ENGINEERING`。真实 2025-10 Ozon 计提原件仍等待不同身份完成来源复核；本变更没有替代该决定，也没有创建任何真实会计分类。

## 修复的不变量

1. 每个“计提组 + 计提类型”按币种分别汇总；只有单币种组合保留兼容的单一金额字段，多币种时该字段为空。
2. 页面显示实际出现的 `positive`、`negative`、`zero`，批准后同时显示合同预期符号。
3. `positive` 只能覆盖金额严格大于零的行，`negative` 只能覆盖金额严格小于零的行；零值或混合符号使用 `either`。
4. 创建批准时复验覆盖区间内每一行；任一失配则拒绝写 Evidence。
5. 每次计算分类状态时再次用实际金额复验批准，确保旧的、损坏的或规则升级前失配的批准不能使状态变为 `ready`。
6. 分类仍然只是控制事实：不生成 Finance Entry、不替代订单收入、不直接进入 CM3。
