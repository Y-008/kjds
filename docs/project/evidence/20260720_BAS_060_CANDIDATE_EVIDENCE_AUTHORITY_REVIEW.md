## 1. 问题

`BAS-059` 已规定候选放行所需的最低证据等级，但 Evidence 的等级仍由上传者在通用入口声明。只要录入者把第三方资料手工选成 A/B，服务端仍可能误把自报标签当成权威结论；而且同一原件对不同指标的适用强度可能不同。

## 2. 已实现合同

- 上传时的 A/B/C/D 只保留为原始录入信息，不再直接驱动生产候选评估。
- 独立 Reviewer/Compliance/Admin 针对一个明确 Evidence 与一个明确指标批准 A 或 B；复核人与上传者必须不同。
- 接受结论必须同时确认：原件真实完整且哈希可复验、来源范围与指标/市场/窗口一致、A/B 权威依据已核对。
- 接受或拒绝都形成不可变 Evidence，并通过保留关系 `candidate_authority_review` 链接原件；同一复核者不能覆盖旧结论。
- 任一有效拒绝优先于接受；无接受、原件损坏、身份/哈希/指标/检查项/理由/血缘失配均失败关闭。
- 原件自报等级不被修改；一个原件可按不同指标形成不同复核结论。
- 通用 Evidence 捕获和 Lineage 接口禁止伪造复核来源与关系；复核证明本身不能再被复核。
- Web 只有 Reviewer/Compliance/Admin 显示复核表单，上传身份只看到交接提示；页面明确复核不代表采购或上架批准。
