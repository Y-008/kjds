## 工程交付

新增 `MarketplaceGrowthPlanner` 深模块与 `POST /v1/marketplace-growth/portfolio-plan`：

- 每个 SKU 必须绑定现有全成本 `ProfitScenario`；
- 同行价格至少三条，市场快照不超过七天，并复验全部 Evidence；
- 服务端计算 P25/P50/P75、当前价格位置、目标 CM3 底价、建议试验价、保本 ACOS、目标 ACOS 上限、每单最大广告支出和最大 CPC；
- 实际成本未通过独立权威复核时，1688 展示价不能解锁广告；
- 高合规风险、无库存、快照过期、成本不完整、目标底价高于市场 P75、价格未对齐、内容分低于 90、评分低于 4.5、评价少于 5、无真实转化率或目标 ACOS 非正时，广告保持关闭；
- 梯类内容计划固定覆盖白底主图、尺寸、止滑结构、安全承重证据、折叠收纳、真实场景和包装/售后七个角色；
- 输出明确 `automatic_marketplace_write=false`、`automatic_ad_spend=false`。

## 首批经营顺序

1. 两步折梯：补齐精确同款同行样本与实际落地成本，随后做受控价格重置；在 2 条评价、14 天 0 单的状态下不投放。
2. 五步折梯：对比 Ozon 4,260–8,427 RUB 的可见竞争区间，核对材质/承重/高度后决定价格与图片；1 条评价时不做规模投放。
3. 园艺锯：公开类目常见约 1,400–2,700 RUB 且评价壁垒很高，先核对规格与当前换算价，再决定是否保留。
4. 涉及品牌、仿币或化妆品的商品先做知识产权/合规审查，不以低价和广告绕过风险。
