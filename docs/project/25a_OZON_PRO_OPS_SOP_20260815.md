## 一、价格体系（当前最大短板：LINYAN 不利 82%、BEIJI 有利仅 14%）

1. 价格指数（Price Index）决定搜索权重与促销资格：
   - 有利（绿）：可上 Хиты продаж、Товар недели、获更多搜索曝光。
   - 中等（黄）：正常。
   - 不利（红）：搜索降权、促销禁入。**红区商品=慢性死亡，必须逐条修或下架。**
2. 修指数的操作（每 SKU 每周一执行）：
   - 商品编辑页查看平台「最低价/建议价」（Ozon 给出的就是竞品基准）。
   - 目标价 = 平台建议价区间上沿或 ≤ 竞品最低价 ×1.05。
   - 尾数用 9（1499₽ 不写 1500₽）；客单 <2000₽ 优先冲绿区，>5000₽ 允许黄区。
3. 定价公式（FBS 跨境，上架前置门）：
   - 落地成本 = (采购价 + 国内运费 + 国际专线运费) × 汇率（1CNY≈13₽，执行时刷新）。
   - 售价下限 = (落地成本 + 平台佣金 + 履约/末端配送费 + 收款费) ÷ (1 − 目标净利率)。
   - 例：采购 30¥ + 运费 20¥ = 50¥≈650₽；佣金 17% + 末端 200₽ + 收款 1.5%，目标净利 20% → 售价 ≈ (650+200)/(1−0.17−0.015−0.20) ≈ **1382₽**。
   - 门槛：**预计净利 ≥ 售价×15%**，平台+物流综合占比 ≤45%，不达标不上架。
4. 每周一「价格巡检」SOP：导出在售清单 → 逐条查指数 → 红区改价或下架 → 改价截图存证 → 周五节点汇报。

## 二、作图规范（Listing 媒体，Ozon 硬规则）

1. 主图硬规则：最小 200×200px，推荐 **1600×1600 白底**；**主图禁止文字/水印/边框/促销字样**；商品占画面 60–80%；一图一产品。
2. 每 Listing 15 张图结构（AI 可生成）：
   - 第 1 张：白底主图（无字）。
   - 第 2–4 张：卖点信息图（俄语）：亮度/材质/防水等级/重量/续航。
   - 第 5–8 张：场景图（露营/家居/工地/浴室等真实使用）。
   - 第 9–12 张：尺寸参数图 + 包装清单图。
   - 第 13–15 张：对比图（同类产品对比/升级点）。
3. 富内容（Rich Content）：2000×1000 信息长图，放详情页顶部。
4. 视频：1:1 或 16:9，5–60 秒，展示使用场景+关键卖点；有视频 Listing 转化 +10–20%。
5. 作图清单（本店主力 SKU 立即做）：折叠床、马桶椅、激光水平仪、折梯、露营灯、头灯、燃气灶——每个 SKU 生成 15 图 + 1 视频脚本。

## 三、标题与 SEO（上架必填）

1. 标题规则：核心关键词放最前；**≤75 字符**（移动端截断）；禁止全大写/表情/价格/「акция/скидка」。
2. 结构模板：`Тип + Бренд + Модель + ключевые характеристики + применение`
   - 例：`Налобный фонарь SUNREI H150, 150 лм, аккумуляторный, IPX5, для кемпинга`
3. 关键词方法：Ozon 搜索框下拉词 + 竞品标题词 + 类目筛选器（颜色/功率/材质）全填。
4. 属性填写率必须 100%（影响筛选曝光）；描述 ≥500 字符，自然埋词 3–5 个。
5. 禁止堆砌：每 Listing 唯一卖点组合，同店不同 SKU 差异化标题。

## 四、上架 SOP（7 步检查单）

1. 毛利门通过（第一节公式）→ 2. 选类目（精确到末级）→ 3. 填 100% 属性 → 4. 标题/描述按第三节 → 5. 上传 15 图 + 视频 → 6. 定价按绿区 → 7. 提交后记录 SKU/日期/成本到三表。

## 五、流量与广告（先自然后付费）

1. 冷启动顺序：价格绿区 → 15 图+视频 → 积分换评价 → 官促报名 → 有自然单后开搜索推广。
2. 官促（免费优先）：Товар недели / Хиты продаж / 11.11 / 黑五 / 新年促，全部报名。
3. 搜索推广（Трафареты）纪律：只投「有 ≥3 评价 + 绿区 + 已出自然单」的 SKU；日预算 ¥50 起；**ROAS≥3 加量、1.5–3 保量、<1.5 连续两节点关投**；广告预算=上周净利×≤30%，不动本金。
4. 卡内推广（Продвижение в карточке）：跑量期再开，占广告预算 ≤30%。
5. 优惠券：新客券 3–5% 拉首单，不叠平台大促。

## 六、评价与消息（店铺权重）

1. 积分换评价（Отзывы за баллы）：新 SKU 上架即开，前 10 条评价 14 天内拿到，50 条为流量拐点；成本约 50–150₽/条，只投新品。
2. 评价回复纪律：4★/5★ 统一感谢模板；3★ 个性化（参考 24f 第五节）；1–2★ 道歉+已整改+退货通道，**不承诺赔偿金额、不承认责任**；已归档 SKU 差评只标记已读。
3. 消息纪律：工作时间 **2 小时内回复**（QI 质量指标）；当前 24 条未读必须当日清零。
4. 差评率红线：品类退货率 >8% 不进；周差评 ≥2 的 SKU 上节点评估表。

## 七、履约（realFBS，错误指数红线）

1. 出库时效：下单后 **≤3 个工作日** 发出（店铺设置展示 5 天）；追踪号 24h 内上传。
2. 错误指数 <2%；取消率 <1.5%；超时=每单罚款并拉低店铺分。
3. 包装：外箱无破损、SKU 标签规范、液体/电池类按平台禁限规则（电池类报关前查 EAC/禁运）。
4. 发货链路：1688 按单采购（48h 代发）→ 深圳货代 → 专线小包（CDEK/邮政末端）→ 妥投。
5. 囤货升级线：连续 2 节点正毛利 + 周单量 ≥10 → 首笔囤货 ≤该 SKU 已验证利润 50%（≤¥3000 起）；费率更优时转 FBO 俄仓。

## 八、财务模型（对账口径）

1. 三表对平：订单表 / 结算表 / 银行流水逐笔对，unmatched=0；银行到账后真人手算 Actual Cash CM3（每周 1h）。
2. 每 SKU 现金毛利 = 售价₽×汇率 − 采购 − 运费 − 佣金 − 末端 − 广告 − 退款摊提。
3. 费用靶心：平台佣金+物流综合 ≤45%（历史 59–62% 必须压回）。
4. 资金纪律：本金只用于启动项；广告/囤货只用已验证利润；利润 30% 强制留存。
