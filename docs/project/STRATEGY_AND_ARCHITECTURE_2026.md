## 1. 文档边界

本文档是本地研究草案，不是主规格、路线图、任务状态表、ADR、验收报告或经营批准。内容与正式真源冲突时，以正式真源为准；草案不得复制或维护实时任务状态、迁移数量、测试数量、Evidence 数量、成熟度评级、PR 状态、行动周历、预算、KPI 或商业定价。

Canonical sources：

- 稳定需求、业务不变量和架构约束：[MASTER_SPEC.md](MASTER_SPEC.md)
- Gate 定义与放行标准：[02_ROADMAP_AND_GATES.md](02_ROADMAP_AND_GATES.md)
- 当前任务、依赖、Owner 和状态：[03_REMAINING_WORK_AND_PARALLEL_PLAN.md](03_REMAINING_WORK_AND_PARALLEL_PLAN.md)
- 已接受的架构决策：[ADR](../adr/)

本草案只能：

1. 摘要正式真源中已冻结的方向；
2. 描述尚未获准的问题与研究假设；
3. 为可能的未来 ADR 提供待验证问题；
4. 明确停止条件和禁止副作用。

任何候选技术在正式触发、取得证据并通过 ADR 前，状态均为 `NOT_AUTHORIZED`。

## 2. 已冻结方向摘要

以下内容只是正式真源的摘要，不在本文档中独立解释状态或扩展授权。

### 2.1 模块化单体

KJDS 当前保持模块化单体。领域规则位于领域/应用服务，外部平台通过连接器或 Provider 协议接入。不得因为技术流行度直接引入微服务、第二后台、第二审批系统或新的基础设施真源。

### 2.2 Evidence 锚定事实

经营事实必须能够追溯到原件、哈希、来源、有效时间、记录时间、血缘和独立复核。`research`、`forecast`、`commitment` 与 `actual` 不得互相冒充。公开示例、第三方摘要、模板和本地草稿不能替代正式 Evidence。

### 2.3 单一动作授权链

所有真实副作用复用正式真源定义的唯一控制链：

`Command → Policy → Approval → Execution-time Revalidation → Result/Readback → Compensation/Rollback`

Agent、Web、脚本、n8n、ComfyUI 和连接器都不得建立旁路授权。高风险动作必须保持申请人与批准人分离，并在执行时重新验证权限、摘要、证据、幂等和风险边界。

### 2.4 G4 验收摘要

G4 关注“到账与利润可证明”，不是仪表板是否展示利润。正式放行标准由路线图定义，核心包括：

- Ozon 平台原件、订单/结算与银行原件可追溯；
- 费用分类与未知费用隔离；
- 订单—平台—银行三方对账；
- 使用明确币种、FX 来源/日期和可复算口径形成实际人民币 CM3；
- 差异、未分类项和证据缺口失败关闭；
- 由有权人员完成人工复核与 Gate Review。

具体阈值和当前完成状态只从 canonical sources 读取，本文档不复制。

### 2.5 G5–G8 方向摘要

- **G5**：用影子模式和对照实验验证建议质量，不把模型输出当成事实或授权。
- **G6**：只在完整授权、幂等、回读、补偿和故障注入通过后，逐项开放低风险受控自动化。
- **G7**：以多个真实 SKU 的同口径经营闭环验证可复制性，不以工程能力数量替代经营结果。
- **G8**：依据真实证据评估 SKU、库存、渠道、工具或组织扩展；所有重大扩展仍需风险预算、Build/Buy/Partner 评审和必要 ADR。

这些方向不授权平台化、多租户、第二市场、自动采购、自动定价、自动发布或无人审批。

## 3. 当前研究问题

研究应先回答问题，再讨论工具：

1. 哪些人工步骤在真实业务中重复发生，并已产生可量化的延迟、错误或成本？
2. 现有模块、接口和运行边界是否已经能解决问题？
3. 新能力会不会形成第二事实源、第二审批链或不可审计的副作用入口？
4. 所需原件、样本、权限、合规结论和独立复核是否已经存在？
5. 最小可逆试验是什么，失败后如何删除或回退而不影响经营事实？
6. 哪个指标触发重新评审，哪个结果要求立即放弃？

在这些问题没有证据前，默认选择是不实施。

## 5. 研究记录最低要求

任何候选研究至少记录：

- 问题陈述及不采取行动的选项；
- 与 canonical requirement/Gate 的对应关系；
- 来源、版本、时间和权威等级；
- 硬约束及淘汰项；
- 可逆试验、最大影响范围和停止条件；
- 真实成本与维护 Owner；
- 替代方案及拒绝原因；
- 失效条件、复审日期和批准人；
- 明确的 `NOT_AUTHORIZED` 边界。

缺少上述项目时，只能保留为研究笔记，不能进入实现 Backlog。

## 6. 禁止从本草案推导的结论

不得从本文档推导以下结论：

- G-1、BAS-026、G0、G1 或任何其他 Gate 已通过；
- 某个真实 SKU、供应商、报价、合规路径或利润已经批准；
- 已授权创建/撤销账号、Ozon Key 或 TOTP 因素；
- 已授权发送 RFQ、付款、采购、发布、投放广告或补货；
- 已选定 Supabase Realtime、TanStack Query、pg_cron、pgvector、FLUX、自建爬虫、多 Agent、公开 CDN 或其他候选技术；
- 已批准固定预算、最大损失、KPI、SaaS 定价或扩展市场。

这些结论必须分别来自机器报告、真实 Evidence、独立复核、经营签署、Gate Review 或已接受 ADR。
