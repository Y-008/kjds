# 23a｜Week 1 启动包（Commander 三条工作线交付物）

本文件是 Phase 0 Day 0–7 的可直接执行物料：供应商跟催、收款通道验证、C0 访谈与 B 公司报价。所有模板只作草稿，发出前由经营负责人（你本人）过目。

## Pack A｜5 家供应商跟催（L1 经营线）

- 每家只发一条消息 + 一张表格；不群发同一文案。
- 要点：产品 D10（10×20mm/黑，具体规格按 SKU Passport）；要实物图、报价单、MOQ、交期、含税运费、起订梯度（200/300/500 件）、是否支持样品单。
- 记录：每家回价、币种、交期、运费、付款方式、联系人、报价有效期；未回复的 3 天后追一次，7 天不回标 `UNRESPONSIVE`。
- 红线：不承诺下单、不付款、不把"公开下单价"当成正式报价；正式报价必须可哈希存证。

模板：

```text
【询价】您好，我是做跨境电商的采购，需要 10×20mm 黑色 [品类名] 一批。请提供：实物图、阶梯报价（200/300/500 件）、MOQ、含税运费、交期、能否先样品。谢谢。
```

## Pack B｜收款通道验证清单（两周窗口）

逐项验证并给结论 `可行 / 不可行 / 待确认`，附来源与费用数字：

1. 俄罗斯银行账户开户路径（个人/法人、KYC、时间）。
2. Ozon 结算币种与到账账户要求（RUB 到俄罗斯账户，还是可结算到境外账户）。
3. 俄→中资金通道：银行电汇、持牌跨境支付公司、USDT 结汇代理（仅记录合法性结论，不执行）。
4. 中国入境合规：外汇申报、税务（个税/企业所得税/增值税）、结汇额度。
5. 总费率测算：换汇点差 + 中间费 + 到账周期；与 SKU 毛利 25% 对比是否成立。
6. 结论格式：一条「可执行路径 + 成本表 + 合规结论 + 风险」，不成立即触发市场切换决策。

## Pack C｜C0 访谈提纲（10 问）

对象：Ozon 中国卖家（微信/电话 20 分钟）：

1. 你目前怎么算一个 SKU 赚不赚钱？多久算一次？
2. 对账（订单、费用、结算、银行到账）每周花几小时？用 Excel 还是软件？
3. 结算单和银行到账对不上的时候，差异一般占多少？
4. 退款/退货/汇率损失你按什么口径估？
5. 最近一次因为算错利润做错决定是什么？损失多少？
6. 如果有工具把"真实到账利润"每周自动算给你，你愿付多少？
7. 是否愿意交脱敏的结算/订单数据来做一次免费诊断？
8. 你的店铺目前几个 SKU？月订单量级？
9. 现在最想解决的三个问题排序。
10. 如果效果好，愿意推荐给谁？

每场记录：真实问题清单、报价心理、数据交付意愿、一个可引用痛点。
