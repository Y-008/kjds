## G0–G1：合法启动与商品准入（3–5 周）

- 明确经营/项目/商品合规/财务/工程负责人。
- 核验 Ozon 账户、合同、权限、履约和收款路径。
- 先用 `candidate-research.csv` 准备三个真实候选的五类指标、原件引用和双来源族，经正式 Evidence 上传与 50/50/30 预检后再确认稳定 SKU，完成商品、俄罗斯合规、样品/质量 Passport。
- 每个 SKU 至少三家真实报价，记录黄金样、实测重量尺寸、包装测试和主备物流。
- 退出证据：3 个 Episode Evidence Package 和 Gate Review 签字。

## G2–G4：从上架到人民币到账（7–11 周）

- Ozon 官方只读同步；CSV/XLSX 暂存行必须转为正式订单、费用、退货、物流和结算事实。
- 商品主图和细节图以真实样品或授权原图为源；场景图只合成背景，俄语/尺寸信息图使用固定模板；全部输出保留来源、处理方式、哈希和人工审核证据。
- 俄语关键词、Listing 和素材经母语/IP/事实/商品外观一致性审核。
- 图片 QA 必须完整记录八项结论、审核依据、可信审核身份和时间；任一失败退回。Listing 草稿只能引用同一 SKU 已批准图片 Evidence，创建草稿只请求发布审批，不调用 Ozon 写接口。
- 一笔测试单和至少一笔真实买家订单走完履约。
- 导入结算与银行文件，完成订单—结算—银行三方对账和实际 CM3。

## G5–G7：验证 Agent，而不是展示 Agent

- 先运行 14 天影子模式，再开放低风险提醒、草稿和提案。
- 高风险生产写入仍禁止；只有完整执行链和故障注入通过后才逐项启用。
- 三 SKU 都完成同口径复盘后，才判断是否具有复制性。

## 冻结区

G7 之前冻结多租户、第二国家/平台、SDK/市场、跨租户网络效应、独立向量库、Temporal 和复杂多 Agent 委员会。出现真实重复需求和明确商业模式后，再通过 ADR 和 G8 解冻。
