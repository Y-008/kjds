## 1a. 加速分支：历史订单先行对账（2026-08-14 确认）

- 触发条件：自家店历史订单 ≥1 个完整结算周期（订单 → 平台结算 → 银行到账）。
- 加速动作（W1 起并行，与 A 线共用人工预算）：① 导出历史订单/结算报表 → ② 导出对应月份银行到账流水 → ③ 按「订单表 / 结算表 / 银行表」逐笔对账键对平 → ④ 1h 人脑复核 Actual Cash CM3 → `CASH_VERIFIED #1`（历史数据版）。
- 里程碑影响：首个现金闭环条件性提前至 **W2–W4**；原保守预测 09-21～10-23 降级为下限，不是取消。
- 不变项：新首单（L3）照常 W2–W3 执行；历史对账只证明管道，不替代新订单闭环。
- 数据原件只进 `.runtime/startup-intake`（Git 忽略，不提交）；观察记录见 `docs/project/evidence/20260814_OZON_OWN_STORE_FINANCE_ANALYTICS_OBSERVED.md`。
- 2026-08-14 实测进度：平台侧历史应计明细已全量导出（三公司 20 个月度报告，7,178 行，净额合计 +572,257.68 ₽，余额 29,565 ₽）；下一步输入 = 对应月份银行到账流水（银行表），到位后即可走“订单表/结算表/银行表”逐笔对平与 1h 人脑复核。
