# T03 三类 Passport

## 商品事实 Passport

- stable_sku_id、变体关系、品牌/IP 主体；
- 材质、功能、颜色、尺寸、净重/毛重、包装；
- 供应商、报价、MOQ、交期、账单/样品证据；
- 锁定字段与允许变化字段；
- UNKNOWN 队列与 Owner。

## 俄罗斯合规 Passport

- HS/品类判断、EAEU/EAC、诚实标签、俄语标签；
- 禁限售、运输危险性、知识产权和素材权利；
- 适用法规/官方来源、复审日和专业复核人；
- 否决项、条件放行项和替代 SKU。

## 样品/质量 Passport

- 样品编号、黄金样、照片/视频、实测尺寸重量；
- 检验方法、抽样方案、包装/跌落/运输测试；
- 缺陷等级、接受阈值、返工/退货条件；
- 人工批准与批准日期。

验收：三类 Passport 均完整、证据可重放、硬事实编造为 0；否则不得上架。
