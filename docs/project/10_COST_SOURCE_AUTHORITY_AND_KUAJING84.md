# 成本权威来源与跨境巴士接入合同

## 结论

不存在一个平台能够成为全部成本的最终权威。每项成本以“实际收款、扣款或开票主体”的原始记录为准；报价只用于售前测算，最终账单用于利润和现金确认。

跨境巴士是其实际经办订单、仓库服务、物流费用和计费重量的一手业务来源，但不是 Ozon 平台佣金、广告、退款、国家税费或银行成交汇率的最终权威。

## 逐项权威来源矩阵

| 成本项 | 售前估算来源 | 最终确认来源 | 跨境巴士角色 | KJDS 处理 |
|---|---|---|---|---|
| 采购 | 供应商报价 | 采购订单、发票、支付流水 | 可关联采购单号和物流单，不单独证明采购价 | `product_cost`，绑定供应商原件 |
| 国内头程 | 承运商报价 | 运单、承运商账单、支付流水 | 若由其仓库/服务经办，可提供订单费用事实 | `domestic_logistics` |
| 仓储/操作 | 仓库公开价、服务报价 | 仓库账单、订单服务明细 | 对其入驻仓和增值服务是一手来源 | `warehousing`；报价与结算分开 |
| 国际物流 | 渠道报价、计费规则 | 实际计费重、物流账单 | 可提供实重、体积重、计费重及订单费用 | `international_logistics` |
| 尾程 | 平台/承运商费率 | Ozon 结算或承运商账单 | 仅在其自身实际收费时是一手来源 | `last_mile` |
| 平台佣金 | Ozon 官方费率 | Ozon 费用/结算原件 | 无最终权威 | `platform_fee`，按版本化费用字典映射 |
| 广告 | Ozon 广告规则 | Ozon 广告账单/报表 | 无最终权威 | `advertising` |
| 退款/退货 | Ozon 政策、历史模型 | Ozon 退款/退货/赔偿明细 | 可补充退件物流和仓库操作费 | `refund`、`return`，不得混为一项 |
| 税费 | 官方税率/海关规则 | 报关单、税单、税务申报 | 无最终权威 | `tax` 或 `customs`，绑定国家与生效日期 |
| 汇率 | 经批准的参考汇率 | 银行、支付机构或平台实际成交/结算汇率 | 无最终权威 | `fx`；参考汇率只能估算，booked FX 才能确认现金利润 |

机器可读真源为 `docs/project/registries/cost_authority_sources.json`。官网只负责规则或参考值，最终确认仍以登录账户中的原始业务凭证为准。

## 已核实的公开 API 边界

正式 API 根地址为 `https://api.service.kuajing84.com`。当前公开合同允许只读获取：

- 订单列表：含原始 `price`、`freight`、`extra`、`fees_price`、`system_price`、`unit_price`；
- 出库信息：含实重、长宽高，以及部分渠道的毛重、体积重、计费重；
- 仓库平台合作服务：含核心/可选服务名称和原始 `gold` 价格；
- 企业 Token：由企业 `client_secret` 换取，有效期由接口响应声明。

这些字段必须原样捕获。没有真实账户样本、订单界面说明和财务人员批准前，不得把字段名直接解释成某个会计科目。

## Ozon 官方数据接入顺序

1. 第一权威：登录账户的应计费用、结算、广告、退货报告及其原始下载文件。
2. 同等机器来源：Seller API 的原始响应；必须保存请求期间、分页、响应哈希和抓取时间。
3. 规则估算：Ozon 官方费率/帮助页面，必须保存生效时间和规则版本。
4. 禁止作为最终权威：搜索摘要、第三方转载费率表、根据售价反推的佣金或物流费。

当前最小接入目标已实现为 `ozon.finance.read`：使用官方 Seller API `POST /v3/finance/transaction/list` 读取单个有界期间和分页，先原样落入 Evidence，再由财务批准费用代码映射；在映射批准前不得自动写入 `platform_fee`、`last_mile`、`return` 或其他成本科目。由于公开官方文档在当前环境仍不可达，接口合同以受控代码、离线测试和运行时原始响应共同校验；真实账户首次执行仍须显式授权并保留 `requires_review`。

## 首份真实财务原件操作卡

目标期间固定为 `2025-10-01` 至 `2025-10-31`。Ozon 官方跨境物流合同第 4 节确认报告期为自然月，并要求平台在次月第 5 个工作日、最迟第 8 个日历日通过个人账户提供月度代理报告、服务文件、适用发票和付款发票；负责人应在收到后 2 个工作日内签署或提出异议，最迟次月 15 日完成确认。因此“应计费用明细”只能证明逐项扣费，不能独自替代月度法律报告、结算和银行到账。

按以下顺序取得原件，不得修改下载文件的内容或手工改表头：

1. 在 Ozon Seller 的“财务 → 应计费用详细信息”选择完整自然月 `2025-10-01` 至 `2025-10-31`、全部应计类型，下载原始 CSV/XLSX。
2. 在个人账户的财务报告/文件区域下载同月可用的代理月报、服务文件、发票或付款发票；缺少某类文件必须记录为 `not_provided`，不能用应计明细代替。
3. 下载同月结算/现金流报告；广告、退货和赔偿如由独立报告承载，分别保存，不把不同报告拼成一张加工表。
4. 记录店铺主体、报告名称、页面期间、导出时间和操作者；这些是来源交接元数据，不写入原文件。
5. 在 Web 选择原文件和相同期间。系统先调用只读预检，只返回 SHA-256、识别类型、行数、字段映射和缺列；预检失败时保留原文件并由工程根据真实表头修订解析合同，运营人员不得另存或改列名绕过。
6. 预检通过后才进入既有不可变 Evidence 上传；上传结果必须显示 `import_id`、原件哈希、固化期间和“未入账”。
7. 由不同 Reviewer/Compliance 身份核对真实账户、期间、非公开样例和导出完整性。复核通过仍不入账。
8. 只对该文件实际出现的原始费用代码逐项批准会计类型、符号和生效区间；全部覆盖后由 Operator 单独晋升事实。
9. 最后用 Ozon 月度报告/结算、银行到账和实际 booked FX 三方对账；没有银行原件只能得到平台侧应计利润，不能得到人民币现金利润。

最小完成证据是：原始文件、SHA-256、结构化期间、预检结果、独立复核 Evidence、费用映射 Evidence、正式 FinanceEntry、对账快照和银行到账原件。页面截图和汇总数字只用于定位报告，不满足该证据集。

## 进入利润账的唯一流程

```text
跨境巴士只读响应/导出
  -> 不可变 Evidence（原文、哈希、effective_at、recorded_at）
  -> 经批准的 provider + raw_code 费用映射
  -> FinanceEntry / Charge
  -> Ozon 结算与银行到账对账
  -> CM1 / CM2 / CM3 和现金利润
```

规则：

1. API 凭证只从运行时密钥源读取，不进入仓库、日志、Evidence 正文或聊天。
2. 只读适配器不得创建、修改、废弃或关联订单。
3. 同一原始订单费用必须使用稳定 `source_ref` 幂等入账。
4. 未批准字段映射一律 `review_required=true`，不得塞入“其他成本”后继续放行。
5. 报价、预估重量和参考汇率只能形成 scenario；实际账单、计费重和 booked FX 才能形成 committed/actual。
6. 同一费用不得同时从跨境巴士和 Ozon 重复计入；以实际扣款主体和对账键去重。

## 利润场景字段与放行门禁

利润场景必须逐项保存 `product_cost`、`domestic_logistics`、`international_logistics`、`packaging`、`warehousing`、`customs`、`tax`、`last_mile`、`platform_fee`、`advertising`、`return`、`fx`、`capital_cost`、`aftersales` 和 `loss`。明确为零或不适用仍须由费用表、合同、规则或财务确认原件证明，不能用缺省值冒充已核实。

`other_cost` 仅为兼容历史草稿的隔离字段：非零即代表存在未分类成本。证据缺项或 `other_cost` 非零时允许保存测算草稿和补证，但不得进入采购评审、样品下单或 Listing 草稿。供应商比较入口上传的“利润假设文件”必须是一份覆盖上述所有非供应商成本项的完整费用包；系统将同一不可变文件逐项绑定，而不是把一条泛化引用视为自动完整。

## 当前完成与剩余阻塞

工程已完成：

- `Kuajing84Provider` 只读订单、出库和仓库服务接口；
- 保留原始费用字段，不做未经批准的语义转换；
- CM2 明确纳入 `warehousing` 和 `tax`，不再强迫藏进 `other`；
- 复用现有 Evidence、费用字典、FX 版本和三方对账。
- `ozon.finance.read` 的 31 天窗口、分页上限、固定官方端点、schema 失败关闭、离线预检、Pilot 限额、原始响应证据和脱敏摘要；
- 财务只读响应不会自动晋升 `ozon_fee`/`ozon_settlement` 或任何成本科目。

真实验收仍需账户负责人完成：

- 在跨境巴士后台申请企业 API 授权并提供运行时密钥引用，禁止把密码或密钥发到对话；
- 导出至少一笔包含订单费用、计费重量、仓库服务和最终账单的脱敏样本；
- 财务负责人逐字段确认 `price/freight/extra/fees_price/system_price/unit_price/gold` 的业务含义；
- 同订单提供 Ozon 费用/结算和银行到账原件，用于查重与三方对账。
- 为独立 Ozon 财务只读凭证配置最小权限运行时密钥，激活允许 `ozon.finance.read` 的 Pilot，并对一个不超过 31 天的期间执行首个受控分页；
- 财务负责人审阅首个原始响应 Evidence，确认分页完整性和费用代码含义后，另行批准版本化映射；当前实现不会代替该批准。
- Ozon 费用码只能在对应费用导入已被独立接受后，通过导入专用审批入口登记；通用费用映射入口对 `provider=ozon` 失败关闭，缺少原件—导入—批准—映射任一血缘均不得晋升正式事实。
