# COM-001 ICP 资格与拒绝清单

用途：筛选首批访谈与设计伙伴候选，不构成销售承诺。

## 理想客户

同时满足：

- 中国境内团队，正在合法经营 1–3 家 Ozon 店铺。
- 50–500 个活跃 SKU，3–20 人团队。
- 至少有一个完整经营周期的商品、费用、退货、结算或到账数据。
- 指定运营负责人和财务负责人共同验收。
- 接受首个 Pilot 只覆盖其中 1 个主体、1 个店铺、3 个用户。
- 愿意提供最小权限只读授权、官方导出和可验证 Evidence。
- 接受纯只读、无盈利保证和 C0 前 `not_for_sale`。

## 立即拒绝

- 要求绕过审批、验证码、限流、平台条款或银行/海关控制。
- 要求假单、诱导评价、流量作弊、侵权或黑产自动化。
- 要求保证利润、全自动运营或首期外部写。
- 拒绝 Evidence、只读授权、数据返还或退出义务。
- 没有真实经营数据或无法指定运营/财务 Owner。
- 首期即要求 SSO、复杂集团集成、定制 SLA 或多平台生产写入。
- 要求 KJDS 代替法律、税务、海关、产品认证或制裁意见。

## 资格问题

1. 当前经营多少家 Ozon 店铺、多少活跃 SKU、多少团队成员？
2. 哪个 SKU 利润、退货、结算或到账问题最无法回答？
3. 目前使用哪些 ERP、表格和人工流程？
4. 谁负责运营事实，谁负责财务验收？
5. 能否提供受权只读数据和原始导出？
6. 哪个可验证结果会让 Pilot 值得继续？
7. 哪个风险或成本会让你立即停止？

## 事实、假设与 UNKNOWN

- 事实：Ozon 商品/财务只读和治理 Evidence 已存在，但实际现金利润仍可能 `no_data`。
- 假设：该 ICP 的利润与对账痛点足以支持付费共创。
- UNKNOWN：首个转化行业、客户采购周期、支持工时和价格接受度。
