# KJDS 跨境数据采集器（Chrome 扩展）

你自己的只读采集扩展：打开 1688 / Ozon 页面后，点一下就把页面上可见的真实数据
（价格、SKU、属性、供应商、搜索结果）发到你本机的采集服务，不经过任何外部服务器。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车。
2. 右上角打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本文件夹：
   `D:\KJDS\kjds\tools\browser_collector`
4. 固定扩展图标到工具栏（可选）。

## 使用

1. 先启动本地采集服务（我来启动，或在命令行运行）：
   ```
   uv run python tools/browser_collector/collector.py
   ```
2. 打开目标页面（1688 详情页、tw.1688.com 货源列表、ozon.ru 搜索/商品页），
   点扩展图标 →「采集当前页面」。数据会保存到：
   `D:\KJDS\kjds\output\browser_capture\`
3. 想批量采集：勾选「自动采集打开的 1688/Ozon 页面」，之后新打开/刷新目标页面会自动采集。

## 页面增强（KJDS 数据卡）

- Ozon 搜索/商品页：每张商品卡下方注入绿色 KJDS 卡，显示 1688 同款采购价（¥/₽）、
  供应商数、产地、成交王；商品页还会给出参考毛利（采购+物流+平台费 vs 页面售价）。
- Ozon 卖家后台：在自家商品行注入黄色 KJDS 卡，显示月销/销额、市场最低价、比价指数、
  1688 采购中位价、参考毛利。
- 弹窗里可开关「页面增强」。数据来自本地服务 `127.0.0.1:8123`，只读显示，不改动页面。

## 说明

- 扩展只读取页面可见内容，不提交表单、不改动页面、不上传外网。
- 已经打开的旧页面需要刷新一次，扩展脚本才会注入。
- 采集服务只监听 `127.0.0.1:8123`，数据只留在本机。
